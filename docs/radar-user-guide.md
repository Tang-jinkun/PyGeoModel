# 雷达覆盖与多雷达协同用户手册

更新日期：2026-07-29  
适用范围：PyGeoModel 的“雷达覆盖”和“多雷达协同”模型。

本手册面向在工作台中配置任务、查看空间结果和下载产物的用户。雷达计算以已选 DEM 为地形依据；雷达站位置、目标高度和距离均采用米制参数。

## 1. 使用前准备

1. 在数据管理中导入并选中可用的 DEM。
2. 确认雷达站经纬度位于 DEM 覆盖范围内，站点之间不要使用重复的站点 ID。
3. 在地图工作台选择“雷达覆盖”或“多雷达协同”模型。

雷达任务会在后台异步执行。提交后可继续浏览地图；进度、完成状态和失败原因在“任务中心”的“运行中”“历史记录”和“日志”中查看。

## 2. 单雷达覆盖

### 2.1 配置雷达站与覆盖范围

在“雷达覆盖”配置面板中，填写或在地图上选取雷达站位置，再设置下列参数。

| 参数 | 含义 | 使用建议 |
| --- | --- | --- |
| 雷达经度、纬度 | 雷达站 WGS84 坐标 | 使用 DEM 范围内的位置。 |
| 雷达高度 | 天线相对地面的高度，单位米 | 塔架或安装高度；不是海拔高度。 |
| 目标高度 | 需要被发现目标相对地面的高度，单位米 | 地面目标可设为 `0`；低空目标填写其离地高度。 |
| 最大探测距离 | 计算半径，单位米 | 距离越大，DEM 采样和计算耗时通常越高。 |
| 扫描模式 | `全向` 或 `扇区` | 全向覆盖使用 360 度；定向雷达使用扇区。 |
| 方位角、波束宽度 | 扇区中心方向与开角，单位度 | 仅扇区扫描时影响水平覆盖范围。 |

“高级参数”用于控制地球曲率、折射系数、体素精度、仰角范围和高度分层。没有明确工程约束时，保留默认值即可。提高体素网格或最大体素数量会增强细节，但会增加任务耗时和结果文件体积。

### 2.2 提交与完成判断

提交后，任务可能经历“排队中”“运行中”“已完成”“失败”状态。

- **已完成**：可以在右侧任务执行面板中打开“查看图层”，或从结果区下载文件。
- **失败**：打开“查看日志”，根据提示修改 DEM、站点位置、计算范围或高级参数后重新运行。
- **历史任务**：可从“历史记录”再次打开图层、下载已保留产物，或使用“重新运行”按当前实现重新计算。

不要把浏览器刷新或关闭任务面板当作取消任务；需要删除记录时，在任务操作中执行删除。

## 3. 阅读单雷达结果

任务完成后，结果会进入左侧图层栏的“任务结果图层”，并在右侧任务/结果面板中显示指标与下载入口。每个图层可单独显隐、聚焦或从图层列表移除。

### 3.1 常用图层

| 图层或产物 | 说明 |
| --- | --- |
| 可见区 | 雷达与目标之间满足地形通视条件的区域。 |
| 遮挡区 | 受到地形遮挡、在本次模型条件下不可见的区域。 |
| 探测范围 | 最大距离、扫描模式和扇区共同形成的水平范围。 |
| 最小可见高度 | 在给定位置达到通视所需的最低目标高度。 |
| 高度分层 | 对不同目标高度分别计算的可见/遮挡结果。 |
| 雷达探测域 GLB | 三维可视化资产，展示雷达覆盖体。 |
| 雷达平台 GLB | 雷达设备模型；仅用于显示，不改变探测计算。 |

“可见”表示由当前 DEM、目标高度、距离和扫描约束推导出的模型结果，不等同于现实环境中的绝对探测保证。建筑物、植被、气象、设备安装误差和电磁环境等未建模因素仍需由工程现场验证。

### 3.2 指标、剖面与目标评估

在任务详情中可以查看覆盖面积、可见面积、遮挡面积、覆盖率等指标。指标用于同一 DEM 和同一计算口径下的方案对比，调整最大距离、站高、扇区或目标高度后应重新运行任务再比较。

- **视线剖面**：在地图上指定目标位置，查看从雷达站到目标的地形剖面与通视状态。
- **目标评估**：输入经纬度和目标海拔高度，获得该点的可见性判定与相关信息。
- **融合分析**：对已完成的雷达结果执行融合，用于进一步比较覆盖关系。

注意：目标评估中的高度是**相对平均海平面的海拔高度**，与覆盖任务中的“目标高度（离地高度）”不是同一概念。

## 4. 多雷达协同

多雷达协同在同一 DEM 上计算多个雷达站的覆盖关系。至少需要 2 个雷达站，每一站都有独立的位置、站高、目标高度、覆盖范围、扫描模式和高级参数。

### 4.1 选择呈现模式

| 模式 | 适用场景 | 主要结果 |
| --- | --- | --- |
| 聚合覆盖 | 大规模站点的覆盖评估 | 联合可见区、重叠区、盲区、覆盖次数、站点汇总。 |
| 协同三维 | 需要检查两个至五个雷达站的空间交会关系 | 聚合结果，另加每站三维探测域、设备模型和协同交会 GLB。 |

协同三维模式仅支持 2 至 5 个雷达站；站点数更多时请选择聚合覆盖。站点 ID 必须唯一，建议使用业务上稳定易读的名称，例如 `R1`、`R2`。

### 4.2 提交前检查

1. 每个站点都位于 DEM 覆盖范围内。
2. 雷达站 ID 不重复。
3. 扇区模式的方位角和波束宽度符合实际部署方向。
4. 协同三维模式的雷达数量为 2 至 5 个。
5. 各站最大距离与 DEM 尺寸相称，避免不必要的大范围高精度计算。

### 4.3 结果图层与三维资产

完成后，“任务结果图层”中应出现可独立控制的结果项：

- **联合可见区**：至少被一个雷达站覆盖的区域。
- **重叠区**：被两个或更多雷达站同时覆盖的区域；地图上以金色强调。
- **盲区**：分析范围内未被任何雷达站覆盖的区域。
- **覆盖次数**：显示每个位置被多少个雷达站覆盖。
- **雷达站**：站点位置和基础信息。
- **各站探测域 GLB**：协同三维模式下，每个站点一项三维覆盖体。
- **各站雷达平台 GLB**：协同三维模式下，每个站点一项设备模型。
- **协同交会 GLB**：协同三维模式下的金色交会体，位于各探测域的重叠空间。

图层列表中的“协同雷达站”是对输入站点的管理显示；真正的计算结果和三维资产位于“任务结果图层”。空的“任务结果图层”通常表示任务尚未加载、任务未完成、任务失败，或历史任务产生于不包含三维资产的旧版本。

### 4.4 看不到金色交会区时

按以下顺序检查：

1. 确认多雷达任务已完成，并打开了“重叠区”和“协同交会 GLB”图层。
2. 确认任务使用“协同三维”而不是“聚合覆盖”模式，且有 2 至 5 个站点。
3. 检查两个站点的最大距离、扫描扇区和仰角是否确实产生共同覆盖；无共同覆盖时不会生成有意义的交会区。
4. 使用图层的聚焦功能定位资产。三维视角过低或位于覆盖体内部时，交会体可能不易辨认。
5. 对旧历史任务执行“重新运行”。最新版本会以独立资产的形式登记探测域、雷达平台和协同交会 GLB。

金色表示几何上的协同重叠呈现，不表示探测概率、目标识别概率或实际数据链路已得到保证。

## 5. GLB 显示说明

三维资产由任务结果管理，而不是普通底图图层。请通过“任务结果图层”逐项显隐或聚焦。

- 雷达平台 GLB 以统一的视觉倍率显示，便于在大范围 DEM 上辨认；该倍率**只改变模型显示大小**，不会改变雷达站位置、覆盖半径、探测高度或计算结果。
- 雷达探测域 GLB 为覆盖体的可视化表达。切入覆盖体内部时，透明面和网格线会比从外部观察更密集；先聚焦资产，再调整地图倾角和缩放。
- 协同交会 GLB 使用金色强调并作为前景资产呈现，避免被其它透明覆盖体完全遮住。

若雷达设备看起来过扁、过小，或旧任务没有平台/探测域资产，请重新运行该任务。旧任务不会在不重新计算的情况下自动生成新版本的 GLB。

## 6. 下载与文件用途

在任务详情或历史记录中选择“下载”。可下载项目取决于任务的实际产物；任务未生成或已不可用的产物不会提供可用下载。

| 文件类型 | 推荐用途 |
| --- | --- |
| GeoTIFF (`.tif`) | 栅格 GIS 分析，例如最小可见高度。 |
| GeoJSON (`.geojson`) | 在 GIS、Web 地图或数据管线中加载边界与区域。 |
| JSON | 读取任务元数据、站点汇总、体素或高度分层清单。 |
| GLB (`.glb`) | 在支持 glTF/GLB 的三维工具中查看场景或设备模型。 |
| BIN | 体素、裁剪体等二进制计算数据，通常配合对应 manifest JSON 使用。 |

建议将下载文件与任务 ID、DEM 版本和配置一并归档。任务摘要和 `output_manifest` 可用于追溯本次计算的输入和输出。

## 7. 常见问题

### 任务失败或页面提示 503

`503 Service Unavailable` 表示前端无法从服务端获得当前请求的正常响应，常见原因包括后端服务未启动、容器正在重建、服务健康检查失败，或上游地图瓦片服务暂时不可用。先刷新任务状态；若多个接口持续失败，请联系部署维护人员检查后端服务和日志。

天地图瓦片加载失败会影响底图显示，但通常不等同于雷达计算结果本身失败。可先在任务中心确认任务状态和日志。

### 图层列表为空

确认任务已完成后，从任务执行面板或历史记录点击“查看图层”。对于较早创建的多雷达历史任务，重新运行可生成当前版本支持的结果图层和三维资产。

### 没有下载按钮

下载入口只对成功生成且仍可用的产物显示。失败任务请查看日志；完成任务若某一项不存在，说明该任务没有产生该类型文件，或该文件已不可用。

### 地图上找不到雷达或覆盖体

在“任务结果图层”中选择对应项目并使用聚焦。检查雷达站经纬度、DEM 范围和当前地图视角；三维资产还需要倾斜地图以便观察高度关系。
