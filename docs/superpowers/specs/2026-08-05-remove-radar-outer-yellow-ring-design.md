# Remove Radar Outer Yellow Boundary Ring

## Goal

Remove the yellow-orange outer ring from the radar 3D GLB model. The ring is the `detection_floor_boundary` scene node generated by `app.scene3d.radar`.

## Design

- Stop constructing the `detection_floor_boundary` mesh node in `write_radar_coverage_glb`.
- Remove the now-unused `FLOOR_BOUNDARY_MATERIAL` definition.
- Keep the detection floor, detectable shell, shell grid LODs, terrain contact markers, unknown boundary, diagnostics, and radar origin unchanged.
- Do not alter frontend rendering or start any service.

## Verification

- Update `backend/tests/test_radar_scene3d.py` so the generated GLB must not contain `radar_result/detection_floor_boundary`.
- Run the focused radar scene test file and the relevant backend test suite available in the repository.
- Confirm the working tree retains the user's existing untracked files.
