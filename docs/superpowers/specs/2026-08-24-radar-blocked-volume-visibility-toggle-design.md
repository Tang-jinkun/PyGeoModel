# 雷达遮挡体独立显隐设计

## 背景

雷达三维 GLB 已经把确定的地形遮挡体输出为独立的 `blocked_volume` 节点，但前端当前只提供整组三维场景显隐和扫描面显隐。用户无法在保留绿色可见体积的同时单独关闭红色遮挡体。

## 目标

- 在三维场景图层行中增加“遮挡”独立显隐开关。
- 关闭开关时只隐藏红色地形遮挡体，绿色可见体积、雷达平台和扫描面保持原状态。
- 单雷达、`aggregate` 融合场景和 `cooperative_3d` 单站场景统一支持。
- 默认显示红色遮挡体。
- 历史 GLB 没有 `blocked_volume` 节点时保持兼容，不报错并隐藏无效开关。
- 不增加 API 参数、不改变任务接口和 GLB 产物类型。

## 方案

### GLB 加载层

`prepareStaticScene` 在加载网格时按以下条件收集遮挡网格：

```text
userData.kind === "blocked_volume"
或
userData.visibility_semantics === "terrain_occluded"
```

`PreparedSceneGlb` 增加遮挡网格集合和可用标志。加载时遮挡网格默认 `visible=true`，旧 GLB 集合为空。

### 场景控制层

场景适配器和 `useMapWorkspace` 增加按任务/场景资产设置遮挡显隐的方法。该方法只遍历已收集的遮挡网格并设置 `mesh.visible`，然后触发地图重绘。

遮挡显隐状态与现有场景状态独立保存，关闭再打开场景时恢复用户最后设置；默认状态为开启。整组三维场景关闭时，场景仍按现有逻辑卸载，重新加载后使用保存的遮挡状态。

### 图层面板

在现有三维场景图层行中，扫描开关旁增加“遮挡”开关：

- `blocked_volume` 存在时显示并默认勾选；
- 不存在时不显示该控件；
- 触发事件只调用遮挡显隐方法；
- 扫描开关、整场景开关和颜色控制互不影响。

单雷达场景显示一项遮挡控制；多雷达融合场景的联合 `blocked_volume` 显示一项控制；协同三维模式的各站点场景分别显示各自控制。

### 颜色和材质

不修改红色语义材质。现有红色材质锁色逻辑继续生效，用户调整绿色场景颜色时不会改变红色遮挡语义。

## 失败和兼容处理

- 场景未加载或任务被卸载时，控制方法返回 `false`，不抛出异常。
- GLB 没有遮挡节点时，场景仍正常加载，遮挡开关不显示。
- 场景包含多个遮挡网格时，开关统一控制全部网格。
- 扫描面显隐继续只作用于 `scan_slice` 节点。

## 测试验收

- 加载含遮挡节点的 GLB 后能识别遮挡网格并默认显示。
- 切换遮挡开关只改变红色网格的 `visible` 状态。
- 绿色体积和扫描面在红色开关切换前后状态不变。
- 多个遮挡网格由同一开关统一控制。
- 没有遮挡节点的历史 GLB 不显示无效控件且正常加载。
- 图层面板能够发出遮挡显隐事件。
- 现有三维场景、扫描面、配色和多雷达场景测试不回归。
